# Explore Local Statistics API OKF

This repository turns the six-page
[Explore Local Statistics API wiki](https://github.com/ONSdigital/explore-local-statistics-app/wiki)
into a bounded, metadata-only Open Knowledge Format bundle.

The bundle catalogues 18 GET operations, their query and path parameters, six
statistical response representations, two boundary representations, source
provenance, and the differences found between the pinned wiki and pinned
`develop` branch implementation. It also emits a review-draft OpenAPI 3.1
description.

It does **not** make the API public or supported. The upstream wiki says the
API is internal/private, may change without notice, and prevents browser
cross-origin requests. The bundle stores no observation values, postcode
results, boundaries, coordinates, credentials, or personal information. It
does not call the API.

## Build

```bash
python3 scripts/build_bundle.py
python3 scripts/build_bundle.py --check
python3 scripts/check_okf.py
python3 -m unittest discover -s tests -v
```

The generated Markdown tree is the normative
[OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/3fcbb9f828c2f23d109c855ee403c3a4c81f3a96/okf/SPEC.md)
layer. Every concept is explicitly `draft`, generated by the deterministic
build process, and linked to the frozen source evidence. None carries a
`verified` event or an Attested Computation claim, so consumers must present
all 37 concepts as unverified. The Explorer, JSON-LD, draft-profile YAML-LD,
OpenAPI and search files are reproducible projections.

The bundle generation checkpoint, wiki commit date and reviewed application
commit date are deliberately separate. `live_status: not-checked` means the
bundle makes no claim about the current wiki, current branch or deployed API.

The public entrypoints are:

- [GitHub Pages landing page](https://chris-page-gov.github.io/okf-els-api/);
- [Open in OKF Explorer](https://chris-page-gov.github.io/okf-explorer/?bundle=https%3A%2F%2Fchris-page-gov.github.io%2Fokf-els-api%2Fokf-explorer.json);
- `bundle/index.md` — normative OKF v0.2 entrypoint;
- `bundle/data/standards/okf-v0.2.json` — deterministic conformance report;
- `bundle/okf-explorer.json` — portable OKF Explorer descriptor;
- `bundle/okf-bundle.jsonld` — semantic DCAT/Hydra/PROV descriptor;
- `bundle/okf-bundle.yamlld` — equivalent byte-stable YAML 1.2/YAML-LD
  projection;
- `bundle/data/openapi.json` — review-draft OpenAPI 3.1 description;
- `bundle/data/review/issues.json` — wiki/source drift register; and
- `bundle/checksums.json` — SHA-256 manifest.
